# Vozes na Tech — Landing Page

One-page estática do projeto **Vozes na Tech** (tecnologia com propósito): educação,
mentoria e oportunidades para ampliar a presença feminina na tecnologia.

## Rodar localmente
Abra o `index.html` no navegador — é 100% estático, sem build.

## Deploy (Vercel)
Projeto estático, sem configuração. Basta importar o repositório na Vercel;
ela serve o `index.html` da raiz automaticamente.

## Pontos a conectar (placeholders)
- **Formulários** (`Quero ser aluna / voluntário(a) / parceiro(a)`, `Doar`): troque os
  links no objeto `FORMS` no `<script>` do `index.html` pelos formulários Google reais.
- **Contato / redes sociais** (footer): e-mail, WhatsApp e Instagram estão como placeholder.

## Identidade
Baseada na logo (coração em ondas sonoras) — gradiente `#2E6BFF → #8B2FE0 → #E8299B`
sobre fundo claro. Marca recriada em SVG inline (sem dependência de imagem).
